# 建築法規くん｜法規・ボリュームチェック

建築設計者向けの法規チェックと住宅初期プラン支援アプリのPoCです。
最初の実装では、次の案件をすぐ検討できるよう、ボリューム概算を優先しています。

## 現在できること

- 敷地面積から道路後退等の除外面積を控除
- 指定建ぺい率と確認済み緩和から建築面積上限を計算
- 指定容積率と前面道路幅員による容積率制限を比較
- 各階床面積と容積対象外面積から容積対象床面積を計算
- 建築面積・容積率・高さの上限利用率と残りを表示
- 90%超過と100%超過を分けて警告
- PDF・PNG・JPEGのローカル選択
- AI図面解析を課金ガード付きで接続できるAPI境界

## 精度優先の設計方針

AIへ一度に最終判断させず、処理を分離します。

1. 図面から事実を抽出
2. 読取不能・資料矛盾・不足情報を検出
3. 建ぺい率・容積率などを決定論的なコードで計算
4. 法規の原則・緩和・条例上乗せを別工程で判定
5. 設計者が根拠と図面位置を確認

`lib/ai/volume-analysis.ts`には、図面事実抽出用の固定命令とJSON Schemaを置いています。
図面解析APIは次の両方が揃わない限り外部通信しません。

```env
OPENAI_API_KEY=
ENABLE_PAID_AI=false
```

費用を発生させる場合だけ、利用者が明示的に`ENABLE_PAID_AI=true`へ変更します。

## 概算範囲の注意

現在の積層表示は面積比による概念図です。以下はまだ自動形状計算に含みません。

- 道路斜線、隣地斜線、北側斜線
- 天空率、日影規制
- 高度地区の斜線形状
- 平均地盤面と敷地高低差
- 2以上の道路、特定道路等の複合緩和
- 地区計画、東京都建築安全条例、区条例

そのため、結果は初期検討用であり、確認申請上の最終判断ではありません。

## 開発

前提はNode.js 22.13以降です。

```bash
npm run test:logic
npm run lint
npm run build
npm test
```

主なファイル:

- `app/page.tsx`: 入力・結果・積層イメージ
- `lib/volume.ts`: 決定論的なボリューム計算
- `app/api/analyze/route.ts`: 課金ガード付き図面解析API
- `lib/ai/volume-analysis.ts`: 精度優先の抽出命令と出力スキーマ
- `tests/volume-calculator.test.ts`: 面積・道路幅員制限の単体テスト
